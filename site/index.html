The PS5 game you dumped, as a Windows program.

AnyPS Conversor takes a decrypted PS5 game or homebrew app and builds a Windows executable from it. One window, three choices.

Download AnyPS-Conversor.exe

Free and open source. A single portable file for Windows 10 and 11; it updates itself from the latest release.

  • Open source under the GPL-2.0
  • SHA-256 published with every release
  • No installer, no account, no telemetry
  • Decrypts nothing, includes no games
  • Ships the official AnyPS5 release, unchanged

What the window asks

  1. Choose the game

    Drop the folder that holds eboot.bin on the window, or an archive with that folder inside: zip, rar, 7z, tar, gz, bz2 or xz. Password-protected archives are extracted too; 7-Zip and WinRAR are not needed.

  2. Where to save

    A new folder named after the game is created there, with the Windows executable, the libraries it needs and the original files in app0. The folder can be moved to any drive afterwards.

  3. Convert to Windows

    The program unwraps the executable, relinks it with AnyPS5 and copies the game files. When it finishes, the same window offers Play now and Open folder.

Everything else, from the processor check to the download of newer versions, happens without asking.

Before you start

Converted games run on the AnyPS5 libraries, so the PC has to meet their bar. The program checks the processor when it opens and says what is missing, if anything.

WindowsWindows 10 version 1607 or later, or Windows 11. 64-bit only.
ProcessorAVX2, FMA, F16C, BMI1, BMI2, LZCNT and MOVBE. In practice, Ryzen and Intel Core from 2015 on. On Intel the conversion switches to the right mode by itself.
GraphicsAny GPU with an up-to-date Vulkan driver.
The gameA decrypted copy: free homebrew, or a dump of a game you own, taken from your own console. Encrypted files and store .pkg packages are refused. The program decrypts nothing and bypasses no protection.

Whether a given title plays well is up to AnyPS5's progress. The game bring-up discussions track titles one by one; if a game converts but does not start, that is where to report it.

After converting

The window shows Play now and Open folder. The converted folder is self-contained: executable, libs and app0. Copy it to another PC that meets the requirements and it runs there as well.

If you ticked the Recycle Bin option, the original files are moved to the Windows Recycle Bin at the end, not deleted, so they can be restored. Archives are extracted in the folder you chose under Where to save, inside a hidden folder that is removed when the conversion ends, so saving to another drive keeps the extraction off C:.

When a conversion fails, its log is kept under %LOCALAPPDATA%\AnyPS-Conversor\logs, the ten most recent for up to thirty days. Apart from the chosen language and folder, nothing else is stored.

How updates work

Each time it opens, the program looks up the newest release on GitHub. If there is one, it downloads the file in the background, checks it against the SHA-256 published with the release, and replaces itself. If you are in the middle of a conversion, the swap waits until you close the window. Nothing about you or your PC is sent; the request is the same one a browser makes to open the releases page.

When AnyPS5 itself publishes a new version, a new AnyPS Conversor is built from it, tested on real homebrew and released, and every installed copy picks it up the same way. To keep a copy on a fixed version, set the environment variable ANYPS_NO_UPDATE.

Built on AnyPS5

All the heavy lifting is done by AnyPS5, by boykopovar and contributors: the relinker that turns the PS5 executable into a native one, and the reimplemented system libraries the game calls into. AnyPS Conversor puts those pieces into a window anyone can use.

RelinkerOfficial AnyPS5 release, embedded unchanged and checked by hash.
Windows librariesOfficial AnyPS5 release, embedded unchanged and checked by hash.
SELF unwrappingC# port of AnyPS5's unwrap_self.py.
Everything elseInterface, archive extraction, languages and updates: this project.

The AnyPS5 version inside each build is listed in the release notes and in build/dependencies.json.

Questions

Is it free?
Yes. GPL-2.0, like AnyPS5. No paid version, no account, no telemetry.
Does it need an installer or administrator rights?
No. Put the file anywhere you can write to, such as your Downloads folder, and run it. Updates replace that file in place.
Is the download safe?
Every release ships an AnyPS-Conversor.exe.sha256 file next to the executable; compare the hash before running. The whole program is open source, so anyone can read what it does.
Where do I get games?
From your own console, or from homebrew authors. This project does not include, host or point to games, firmware, keys or certificates, and issues containing them are removed.
Something went wrong. Where do I ask?
If the conversion itself failed, open an issue with the log from the logs folder. If the game converted but does not play, the AnyPS5 discussions linked above are the right place.
