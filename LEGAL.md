## English

**What the program is.** AnyPS5 Conversor is a free and open source graphical interface for the
[AnyPS5](https://github.com/boykopovar/AnyPS5) tools. It is meant to run on Windows PS5 software that
the user has the right to use, such as freely distributed homebrew and copies dumped from the user's
own console.

**What the program does not do.**

- It does not include, distribute, host or point to sources of games, firmware, keys, certificates
  or proprietary libraries.
- It does not decrypt anything or circumvent any technical protection measure. It only accepts
  executables that are already decrypted and refuses encrypted files, including store `.pkg`
  packages.
- It does not collect data, require an account or connect to the internet. It only opens a link
  when the user clicks it.
