# Segurança / Security

**Português.** Não abra issue pública para falhas de segurança. Use o relato privado do GitHub:
aba **Security** → **Report a vulnerability** deste repositório. Só a versão mais recente recebe
correções. Falhas no relinker ou nas bibliotecas do AnyPS5 devem ser relatadas ao
[AnyPS5](https://github.com/boykopovar/AnyPS5).

Para conferir um download, compare o SHA-256 do `AnyPS5-Conversor.exe` com o arquivo `.sha256`
publicado no mesmo release.

**English.** Do not open a public issue for security problems. Use GitHub's private reporting:
**Security** tab → **Report a vulnerability** in this repository. Only the latest version receives
fixes. Problems in the AnyPS5 relinker or libraries should be reported to
[AnyPS5](https://github.com/boykopovar/AnyPS5).

To verify a download, compare the SHA-256 of `AnyPS5-Conversor.exe` with the `.sha256` file
published in the same release.
